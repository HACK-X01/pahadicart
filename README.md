> **"Aapka Apna Pahadi Bazaar • Har Mod Par Aapke Saath"**  
> First dedicated 2-hour hyperlocal quick-commerce & rapid delivery ecosystem purpose-built for the steep ridges, pedestrian mall roads, and staircase doorstep navigation of Himachal Pradesh.

## 🚀 5 Interconnected Portals

1. **🌐 Super Hub Platform Launcher (`/`):** Ecosystem dashboard with 1-Click Mountain Order Lifecycle Simulator.
2. **🏢 Super Admin Command Tower (`/admin/`):** Real-time Triad Tracker, Rider Fleet GPS Radar, Financial P&L Ledger, and Dynamic Weather Surges.
3. **🛍️ Customer Ordering PWA App (`/customer/`):** Multi-town catalog (Solan, Shimla, Dharamshala), 🎤 *"बोलकर ऑर्डर करें"* Voice-to-Cart, 📍 Live Rider GPS Tracking, WhatsApp Hinglish Bot, and Deep Valley Tunnel Mode.
4. **🏪 Vyapar Mandal Merchant Shop (`/merchant/`):** Counter dispatch with 🔔 *"Ghar Ki Ghanti"* chime, automated Hindi voice call alert, 📷 Camera Barcode Scanner, and 🖨️ 58mm KOT Thermal Receipt.
5. **🛵 Pahadi Rider Mobile Cockpit (`/rider/`):** Glove-friendly UI, 📦 Batched Route Staircase Optimizer (~38% fatigue reduction), OTP verification, and SOS Emergency Alert.

## 📦 Deployment Instructions

### Deploy to Vercel (Recommended):
1. Push this repository to GitHub.
2. Go to [Vercel](https://vercel.com) and click **"Add New" ➔ "Project"**.
3. Import this GitHub repository.
4. Leave framework preset as **Other** and root directory as `./`.
5. Click **Deploy** — your live `*.vercel.app` URL is ready in 30 seconds!

### Deploy to Netlify:
1. Push this repository to GitHub.
2. Go to [Netlify](https://app.netlify.com) and select **"Add new site" ➔ "Import an existing project"**.
3. Choose your GitHub repository.
4. Set publish directory to `.`.
5. Click **Deploy Site**!
